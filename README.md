# AI-Based Java Quiz Application

An AI-powered Java Quiz Application developed using Java, Spring Boot, Spring MVC, Spring AI, and Thymeleaf. The application dynamically generates Java programming questions using AI and provides an interactive quiz experience with automatic answer validation and scoring.

## 🚀 Features

- **AI-Generated Questions:** Dynamically generates Java programming questions using Spring AI.
- **Multiple Question Types:** Supports MCQ, Fill-in-the-Blank, and True/False questions.
- **JSON Processing:** Uses Jackson ObjectMapper to deserialize AI-generated JSON responses into Java objects.
- **Session Management:** Uses HTTP Session to maintain quiz questions, user answers, and quiz progress.
- **Automatic Evaluation:** Validates submitted answers and calculates quiz scores.
- **Interactive UI:** Provides a user-friendly quiz interface using Thymeleaf.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Backend Framework:** Spring Boot, Spring MVC
- **AI Integration:** Spring AI
- **Frontend:** Thymeleaf, HTML, CSS
- **JSON Processing:** Jackson ObjectMapper
- **Session Management:** HTTP Session

## ⚙️ Application Workflow

1. The user starts the Java quiz.
2. Spring AI generates Java programming questions based on predefined prompts.
3. AI-generated JSON responses are processed using Jackson ObjectMapper.
4. Questions are displayed through the Thymeleaf interface.
5. User responses are maintained using HTTP Session.
6. Submitted answers are evaluated and the final score is displayed.

## 🎯 Project Objective

The objective of this project is to demonstrate the integration of Generative AI with Java Spring Boot applications while building an interactive quiz platform that dynamically generates programming questions.
